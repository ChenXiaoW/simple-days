# Simple Days · 日程管理

[English](README.md) · [GitHub 仓库](https://github.com/ChenXiaoW/simple-days) · [发布说明](RELEASING.md)

公开发布版本为 **0.6.12**，插件 ID 为 `simple-days`，作者为 ChenXiaoW。界面跟随 Obsidian 的语言设置：中文环境显示中文，英文及暂未支持的其他语言显示英文。日历日期、星期、分类、弹窗、设置、命令、提示和日记生成内容均随之切换；日程标题、备注等用户内容及已配置的日记路径保持原样。修改 Obsidian 语言后请重启 Obsidian。最低要求 Obsidian 1.7.2。Obsidian 1.13 及以上版本支持在全局设置搜索中查找本插件设置。


## v0.6.2 详情页直接勾选备注任务

- 详情弹窗中的 Markdown 任务框可以直接勾选或取消，自动保存到日程；启用日记同步时更新对应日记。
- 每项任务独立保存，不会自动把整个日程标记为完成。底部“标记完成”仍控制整个日程。
- 保存期间暂时禁用任务框，失败时恢复原勾选并提示。备注已被其他操作修改时不覆盖新内容。
- 编辑表单中的预览保持只读，编辑内容仍须保存日程后生效。

## v0.6.1 Markdown 备注与放大编辑

- 备注支持输入 Markdown 原文，可切换“编辑 / 预览”。详情中也按 Markdown 显示标题、加粗、清单、引用、链接、代码块和表格。
- 拖动备注框右下角可调整高度；点击“放大备注”可打开大窗口编辑或预览。点击“收起”、右上角关闭或按 Esc 都会保留内容，回到表单后保存日程才会写入数据。
- 备注中的 Obsidian 双链可点击打开，链接和附件按笔记库根目录解析。编辑表单的预览只展示任务状态；v0.6.2 起详情弹窗支持直接勾选。
- 同步到日记时保留 Markdown 的段落与缩进，避免首行标题、清单和代码块被当成普通文字。备注原文保留首尾空格，旧的纯文字备注继续可用。

## v0.6.0 跨天日程与拖拽移动

- 新建和编辑时填写开始日期、结束日期，支持跨天的定时日程与全天安排。旧日程没有结束日期时仍按单日处理。
- 全天安排包括结束日期当天；定时安排从开始日期的开始时间持续到结束日期的结束时间。结束于次日 00:00 时，不占用次日。
- 月历在涉及的每一天显示日程，后续日期带“续”标记；周视图按每天的时间范围分段展示，全天安排显示在顶部全天行。
- 桌面端可把月历日程条、周视图日程块和全天日程拖到其他日期。落点高亮，保存后同步刷新。
- 移动保留原起止时间与日期跨度。从跨天日程中间的某一天拖动时，以拖起的那一天对齐目标日期，整条日程一起移动。
- 跨月或跨周拖动：拖着日程停留在右上角的上一页 / 下一页箭头约半秒，翻页后松到目标日期。
- 拖到周时间轴时只更改日期，时间保持不变。调整时间可以打开详情 → 编辑日程；触屏端也可通过编辑日期移动。
- 同一条跨天日程在本月统计里只计算一次；日记按每天的实际时间写入，并保留完整起止范围。移动、缩短日期、完成或删除会同步更新各天日记，保留正文。
- 点击跨天日程的某一天打开详情，再点“打开日记”，打开该天的日记。同步为日历到日记的单向同步。
- 保存失败时保留原位置并提示重试；更新已有数据无需迁移，保留 data.json 即可。

## 安装与升级

1. 从 [Releases](https://github.com/ChenXiaoW/simple-days/releases) 下载三个插件文件，放到笔记库的 `.obsidian/plugins/simple-days/`。
2. 确认该目录直接包含 `main.js`、`manifest.json`、`styles.css`。
3. 在 Obsidian 设置 → 社区插件中启用“Simple Days”。
4. 点击左侧日历图标，在主编辑区的独立标签页打开日历。

**升级已有版本时，只替换 `main.js`、`manifest.json`、`styles.css`，保留原来的 `data.json`。然后关闭并重新启用插件，或重启 Obsidian。**

也可在 Obsidian 社区插件页面更新 Simple Days，无需先卸载。若只提示“安装失败”，先重启后重试；仍失败时，可关闭插件，将同一版本的三个安装文件覆盖到现有插件目录，再重启 Obsidian，保留 `data.json`。旧版 `obsidian-schedule-manager` 与 Simple Days 只启用一个。该通用提示无法区分下载、替换文件或加载失败，不能直接认定为日程数据不兼容。

完整源码随包提供；运行插件不需要安装开发工具。

## 操作入口

- 命令面板 → **Simple Days：打开日程管理**：打开或复用主编辑区标签页，不覆盖当前笔记。
- 命令面板 → **Simple Days：在标签页中打开月视图**。
- 日程管理页面标题栏的概览按钮支持打开和关闭右侧日程概览小工具，提示文字随状态切换；左侧工具栏不设置独立的概览图标。命令面板 → **Simple Days：在侧边栏打开日程概览** 仍可直接打开小工具。
- 命令面板 → **Simple Days：新建日程**。
- 命令面板 → **Simple Days：将已有日程同步到日记**。
- 点击日程条打开详情；点击日期，下方显示当天清单。空白日期格可双击新建，键盘可选日期后点击“新建”。
- 周视图的空白时间格支持点击 / 拖动创建；键盘聚焦时间格后按 Enter。触屏可点击时间格。
- 标签和参与人用中英文逗号、顿号或换行分隔。

## 手机与电脑间同步

- 完整同步建议包含 `.obsidian/plugins/simple-days/data.json`，其中保存日程、备注待办、完成状态、分类和设置。如果只同步了日记 Markdown 文件，可使用下方“从日记导入/重建日程”手动恢复日历。
- 两端使用相同插件 ID 和版本；部分同步工具默认忽略隐藏目录或插件数据，需要检查其设置。
- 拉取后自动重新加载数据，刷新月/周视图和侧边栏；返回 Obsidian 前台或打开日历时也会检查。手机端在应用可见且日历或概览打开时，每 15 秒补查一次。
- 可运行命令 **Simple Days：重新加载同步后的日程** 立即刷新；提示中的日程数量可用于核对数据是否已拉取。
- 重新加载只读取并验证完整文件，不回写数据、不自动改写日记；文件缺失、不完整或格式异常时保留当前内容并提示。
- 此功能不负责两台设备同时修改的逐字段合并；切换设备编辑前，先完成同步。

## 从日记导入/重建日程

适用于手机只拉取了日记、未同步插件 `data.json`，导致日历和侧边栏没有日程的情况。

1. 先完成日记文件的远端拉取。
2. 打开命令面板，运行 **Simple Days：从日记导入/重建日程**；也可在插件设置中选择 **日记 → 日历 → 扫描并导入**。
3. 点击“扫描日记”，查看可导入列表、重复数量及跳过的记录。
4. 点击“导入新增日程”，保存后日历和侧边栏立即刷新。

- 扫描和导入不会改写原日记，也不会覆盖已有日程；重复导入会跳过已存在的记录。
- 只读取插件生成的标记区块，兼容旧版中英文日记。扫描范围为当前仓库内的 Markdown 文件，也能发现移动目录后的日记；普通待办不会导入。
- 恢复日期、完整跨天起止、时间、完成状态、地点、标签、参与人和 Markdown 备注；同一跨天日程在多天日记中的记录自动合并。
- 旧日记没有保存分类和原始日程 ID，因此恢复后默认分类为“工作”，并生成新的 ID；设置不会从日记恢复。
- 日期按区块内的 `### YYYY-MM-DD` 标题、完整跨天起止、自定义日记文件名格式或 `YYYY-MM-DD.md` 文件名识别。自定义嵌套目录需检查日记目录及格式设置；只有月份的单日日记需补充明确日期标题，不会猜测缺失日期。
- 多个副本内容冲突、与已有日程冲突、格式或日期无法识别的记录会列出并跳过。导入只补充缺失日程，不负责修改、删除或自动双向同步。
- 完成恢复后再编辑日程或执行“写入日记”，正常日记同步仍会用日历内容更新生成区块。完整保留分类和设置仍建议备份并同步 `data.json`。

## 日记联动

- 默认自动同步。优先读取 Obsidian 核心“日记”插件的目录、日期格式和模板；未配置时使用 `日记/YYYY-MM-DD.md`。
- 新建、编辑、完成、删除或移动日期会更新对应日记；旧日期的日程区块会清理，空日记不会被删除。
- 日程写在下面两个标记之间，日记的其他内容保留。个人正文请写在区块之外。

```markdown
<!-- obsidian-schedule-manager:start -->
## 日程

- [ ] 15:00 – 16:00 组织架构调整说明会
  - 地点：总部 3F · 星空会议室
  - 参与人：李明、陈欣
  - 标签：#重要 #会议
  - 备注：

    ### 会前准备
    - [ ] 准备人力盘点表
    - [ ] 阅读 **调整方案**

<!-- obsidian-schedule-manager:end -->
```

- 这是 **日历 → 日记的单向同步**。直接编辑日记里的同步区块不会反向更改日历，下次同步将以日历内容更新。
- 新建日记支持核心模板的 `{{date}}`、`{{date:格式}}`、`{{time}}`、`{{time:格式}}`。不执行 Templater 等第三方模板脚本。
- 插件启动后补同步已有日程；也可在设置 → Simple Days → **日历 → 日记** 中点击 **写入日记**。
- 写入结果会显示本次更新数量及实际日记路径（最多显示 3 个）。内容已经一致时显示更新 0 个文件；日历为空且没有已跟踪路径时会打开导入窗口，方便恢复已拉取日记。
- 使用自定义日记配置时，关闭“使用 Obsidian 日记配置”，填写库内目录和日期格式，再点击“写入日记”。第三方日记插件的配置需手动填写。
- 同步失败会保留已保存的日程并显示提示；修复路径或区块标记后重试。界面里的自动同步提示表示已启用同步，不表示最近一次写入一定成功。
- 日程数据保存在插件目录的 `data.json` 中；此文件应随笔记库备份。
